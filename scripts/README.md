# Скрипты для AutoHub AI

## Массовая загрузка запчастей (bulk_import.py)

Скрипт для импорта запчастей и артикулов из CSV файла в базу данных.

### Использование

#### 1. Создание примера CSV файла

```bash
python3 scripts/bulk_import.py sample --output sample_import.csv
```

Создаст файл `sample_import.csv` с примерами данных.

#### 2. Импорт данных из CSV (с проверкой)

```bash
python3 scripts/bulk_import.py import --file data.csv --dry-run
```

Опция `--dry-run` покажет, что будет импортировано, но не сохранит данные в БД.

#### 3. Импорт данных в базу

```bash
python3 scripts/bulk_import.py import --file data.csv
```

### Формат CSV файла

CSV файл должен содержать следующие колонки:

- `internal_code` - Внутренний код запчасти (обязательно, уникальный)
- `canonical_name` - Каноническое название запчасти (обязательно)
- `description` - Описание запчасти (опционально)
- `article_numbers` - Артикулы в формате `артикул1:производитель1;артикул2:производитель2`

#### Пример строки CSV:

```csv
internal_code,canonical_name,description,article_numbers
PART-001,Масляный фильтр Mann W 712/75,Качественный масляный фильтр,W712/75:Mann-Filter;W71275:Mann-Filter
```

#### Формат артикулов:

- С производителем: `W712/75:Mann-Filter;W71275:Mann-Filter`
- Без производителя: `W712/75;W71275`
- Можно комбинировать: `W712/75:Mann-Filter;W71275`

### Веб-интерфейс для массовой загрузки

Альтернативный способ загрузки через админ-панель:

1. Войдите в админ-панель: `/admin/login`
2. Перейдите на страницу: `/admin/bulk-import`
3. Скачайте пример CSV или подготовьте свой файл
4. Загрузите CSV файл через веб-форму
5. Просмотрите результаты импорта

### Требования

- Python 3.8+
- Установленные зависимости из `backend/requirements.txt`
- Настроенная переменная окружения `DATABASE_URL` или файл `.env`

### Примечания

- Запчасти с дубликатами `internal_code` будут пропущены
- Файл должен быть в кодировке UTF-8
- Артикулы с одинаковым номером для одной запчасти создадут ошибку уникальности
