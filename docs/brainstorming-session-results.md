## Technique Session #1: First Principles Thinking

**Duration:** В процессе
**Description:** Разбор проекта на фундаментальные компоненты и определение критически важных функций для MVP

### Критические функции (определены пользователем):

1. **Масштабный корпоративный визуал**
   - Современный, интересный, необычный дизайн
   - Контент для главной страницы (требуется проработка)

2. **Публикация объявлений (без регистрации)**
   - Пользователь указывает только контактные данные (телефон, WhatsApp или Telegram)
   - Обязательные поля при публикации:
     - Артикул запчасти
     - Фотографии
     - Состояние (новое/б\у)
     - Цена
     - Контактные данные
     - Описание (любые подробности о запчасти)

3. **AI-обработка объявлений через Google Gemini**
   - После нажатия "Опубликовать" AI:
     - Автоматически ищет информацию о запчасти по артикулу
     - Формирует структурированное описание
     - Создаёт корректное название объявления
     - Дополняет характеристиками запчасти

4. **Система модерации (обязательная)**
   - Простая админка для модерации
   - Отображение исходных данных пользователя
   - Отображение результатов обработки AI (или их отсутствие)
   - Объявление публикуется только после подтверждения админом

5. **Система артикулов и внутренних ID**
   - Пользователь вводит артикул вручную (без валидации)
   - Один артикул = одна запчасть
   - Один артикул может иметь много объявлений от разных продавцов
   - **ВАЖНО**: Одна запчасть может иметь несколько разных артикулов
   - **Решение**: Создать внутренний ID (свой номер), к которому привязываются артикулы
   - Для MVP: внутренний номер и артикул создаются вручную при модерации в админке
   - Связывание артикулов будет вручную обрабатываться в будущем

6. **Карточки объявлений**
   - Отображение информации о запчасти
   - Контактные данные для связи с продавцом
   - (Детали требуют проработки)

7. **Поиск по артикулам и фильтрам**
   - "AI-powered поиск" - маркетинговая формулировка
   - Реальная реализация: обычный текстовый поиск по артикулу или названию
   - Пример: поиск "гофра кардана на катер" → показывает все подходящие гофры кардана
   - Фильтры (требуют уточнения для MVP)

8. **Массовая загрузка объявлений админом**
   - Админ должен иметь возможность загрузить много объявлений сразу
   - Можно даже напрямую в БД (без UI)
   - Начальная стратегия: собрать объявления с других сайтов и вручную перенести
   - После добавления в БД - товары сразу отображаются на сайте

### Что НЕ входит в MVP:

- ❌ **Система профилей/аккаунтов пользователей** - слишком сложно для 5-дневного спринта
- ❌ **Автоматическая валидация артикулов**
- ❌ **Автоматическое связывание артикулов к одной запчасти** - будет вручную в будущем

### Insights Discovered:

- **Модерация как критичный фильтр**: Вся ответственность за качество контента лежит на модераторах
- **Двойная система идентификации**: Внешние артикулы + внутренние ID для гибкости
- **Баланс между AI-маркетингом и реальностью**: AI реально работает для обогащения объявлений, но поиск обычный
- **Стратегия холодного старта**: Ручное наполнение контентом с других площадок для создания объёма

### Notable Connections:

- Простота публикации (без регистрации) + обязательная модерация = защита от спама
- AI-обработка снижает барьер входа для продавцов (не нужно писать подробное описание)
- Внутренние ID позволят в будущем группировать аналоги и кросс-номера

## Technique Session #3: SCAMPER - Детальная проработка элементов

**Duration:** В процессе
**Description:** Систематическая детализация каждого компонента проекта

### Детальные спецификации:

**1. Брендовые карточки на главной странице:**
- Количество брендов: 12 (адаптивно в зависимости от размера экрана)
- Формат: Статические карточки
- Содержание каждой карточки:
  - Картинка, относящаяся к бренду
  - Подпись с названием бренда
- Поведение: Клик → переход в каталог с применённым фильтром по выбранному бренду
- Примеры брендов: Audi, BMW, Mercedes, Toyota, Volkswagen, и т.д.

**2. Форма публикации объявления:**
- **Фотографии:**
  - Максимум: 10 фото
  - Форматы: любые (jpg, png, webp, и т.д.)
  - Предпросмотр: не требуется
- **Защита:**
  - ❌ Капча не нужна
  - ✅ Защита через обязательную модерацию человеком

**3. AI-обработка и модерация:**
- **Процесс:**
  1. Пользователь публикует объявление
  2. Система отправляет данные на обработку Google Gemini
  3. Объявление попадает в админку со статусом "В обработке AI"
  4. После ответа Gemini: статус меняется на "На модерации"

- **Обработка ошибок Gemini:**
  - Если Gemini не отвечает или возвращает ошибку:
    - Статус: "На модерации" (с пометкой об ошибке AI)
    - В админке показывается: "AI не смог обработать"
  - Модератор может повторно отправить на обработку AI (неограниченное количество раз)

- **Функционал модератора:**
  - Кнопка "Отправить на обработку AI повторно"
  - История попыток обработки (опционально для будущих версий)
  - Возможность одобрить объявление даже без AI-обработки

**4. Упрощённая логика поиска:**
- Показываем только прямые результаты поиска
- Если результатов нет: простое сообщение "Такого товара нет"
- ❌ Убрана сложная логика с "похожими товарами" для упрощения разработки

### Insights и оптимизации:

**Что упростили для MVP:**
1. ✅ Убрали рекомендации похожих товаров → экономия 2-3 часа разработки
2. ✅ Убрали капчу → экономия 1 час
3. ✅ Статические бренды вместо динамических → экономия 1-2 часа
4. ✅ Tailwind CSS вместо сложных UI-китов → гибкость и скорость

**Что сохранили для качества:**
1. ✅ Повторная отправка на AI → надёжность обработки
2. ✅ Модерация как фильтр качества
3. ✅ Mobile-first подход
4. ✅ Корпоративный вид

**Итоговая экономия времени: ~5-7 часов** 🎉
**Новая оценка: 26-36 часов** (вместо 33-43) - теперь реалистично для 5 дней!
